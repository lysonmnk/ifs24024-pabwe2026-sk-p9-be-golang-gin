# Definition of Done (fitur selesai jika semua tercentang)

- [x] Security: LULUS
- [x] QT: SIAP RILIS, edge cases diuji
- [x] DevOps: deploy sukses, rollback siap
- [x] Commit sesuai Conventional Commits, keputusan penting dicatat
